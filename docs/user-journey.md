# ユーザージャーニー

## 主要フロー

### フロー1: トップ画面からクイズ開始

**アクター**: 子ども  
**ゴール**: クイズを開始する  
**前提条件**: アプリを開いてトップ画面が表示されている

| ステップ | ユーザーアクション | システム応答 | 備考 |
|---|---|---|---|
| 1 | トップ画面を開く | 3つのメニューカードを表示 | 初回表示 |
| 2 | 「クイズをはじめる」を押す | クイズ画面へ遷移 | 1タップ操作 |
| 3 | 1問目を表示 | 選択肢を表示 | 以降2〜3問目へ |

**完了条件**: クイズ1問目が表示される  
**エラーケース**: 画面遷移エラー時はトップ画面に戻し再試行導線を表示

### フロー2: クイズ完了から結果確認

**アクター**: 子ども/保護者  
**ゴール**: 正解数と星を確認する  
**前提条件**: クイズを開始している

| ステップ | ユーザーアクション | システム応答 | 備考 |
|---|---|---|---|
| 1 | 問題に回答 | その場で正誤表示 | 視覚的に分かりやすく |
| 2 | 3問目まで回答 | 結果画面へ遷移 | 自動遷移 |
| 3 | 結果を確認 | 正解数・星数・再挑戦ボタン表示 | ほめる文言を表示 |

**完了条件**: 結果画面が表示される  
**エラーケース**: 途中離脱時はトップに戻って再開

## 画面一覧

| 画面名 | URL/パス | 主な機能 | 認証要否 |
|---|---|---|---|
| トップ | `/` | 3導線の表示 | 不要 |
| クイズ | `/quiz` | 3択問題表示と回答 | 不要 |
| 結果 | `/result` | 正解数/星数表示 | 不要 |
| ミッション | `/mission` | 今日のミッション表示 | 不要 |
| 星コレクション | `/stars` | 星の表示 | 不要 |

## 状態遷移

```
トップ → クイズ開始 → 回答中(1/3,2/3,3/3) → 結果表示 → もう1回
```

## エッジケース

- ブラウザ更新で進行状態が消える: MVPではトップに戻して再挑戦
- 連打による誤入力: 回答後は次へボタン表示まで選択肢を無効化
