# プロダクト要件定義書 — AI Mentor Bot

## プロダクト定義

教育プログラム受講者の学習を能動的に伴走するチャットBot。
単なるQ&A対応だけでなく、停滞検知・離脱防止・進捗管理を統合した「AIカリキュラム伴走OS」。

## ターゲットユーザー

- **プライマリユーザー**: 教育プログラムの受講者（20〜50名規模）
- **セカンダリユーザー**: プログラム運営者（進捗確認、介入判断）

## MVP機能

1. **チャットDMでの対話応答**
   - 受講者のメッセージに対し、カリキュラム文脈を踏まえた応答を返す
   - 受け入れ基準: 応答時間3秒以内、カリキュラム内容に基づく回答

2. **停滞検知→プロアクティブDM**
   - 60分間隔でスキャンし、24時間以上無活動の受講者にDMを送る
   - 受け入れ基準: 検知精度90%以上、誤検知率5%以下

3. **コード提出→AIレビュー**
   - GitHub URLを提出すると、AIがコードレビューを返す
   - 受け入れ基準: レビュー生成時間30秒以内、建設的なフィードバック

4. **ホーム画面での進捗表示**
   - チャットアプリのホーム画面に学習進捗を表示
   - 受け入れ基準: 現在のModule、完了率、次のアクションを表示

## ユーザーストーリー

- **US-01**: 受講者として、チャットDMで質問したい、カリキュラムの内容について助けてもらうために
  - 受け入れ基準: カリキュラム文脈を踏まえた回答が返る

- **US-02**: 受講者として、学習が止まった時に声をかけてほしい、モチベーションを維持するために
  - 受け入れ基準: 24時間無活動で温度のあるDMが届く

- **US-03**: 受講者として、コードを提出してフィードバックがほしい、学習の質を上げるために
  - 受け入れ基準: GitHub URLを送るとAIレビューが返る

## スコープ外

- **Web管理画面**: Phase 2以降。MVP段階ではFirestoreコンソールで確認
- **複数ワークスペース対応**: Phase 2以降。MVP段階は単一ワークスペース
- **リアルタイム音声・ビデオ**: 対応しない
- **受講者間のマッチング・グループ機能**: 対応しない
- **多言語対応**: 日本語のみ

## 非機能要件

- **パフォーマンス**: チャット応答 3秒以内、レビュー生成 30秒以内
- **可用性**: Cloud Functions + Firestoreの標準SLA（99.95%）
- **スケーラビリティ**: 受講者50名対応（MVP段階）
- **コスト**: LLM APIコスト月額$100以下

- Phase 3: カリキュラム自動調整、受講者間コラボレーション
